# Docs

Project documentation for HomePulse.

## Files
| File | Description |
|------|-------------|
| `API_DOCS.md` | REST & WebSocket API reference |
| `DATABASE_SCHEMA.md` | Prisma schema overview & relationships |
| `DEPLOYMENT.md` | Deployment guides (Docker, CI/CD, infra) |
| `QR_SYSTEM.md` | QR code generation, scanning & campaign flows |
| `SAFETY_TRUST_POLICY.md` | Safety scores, SOS alerts, trust scoring rules |
| `USER_FLOWS.md` | End-user journey maps & feature walkthroughs |

## Usage
Read in order for onboarding:
1. `DATABASE_SCHEMA.md` — understand data model
2. `API_DOCS.md` — learn endpoints
3. `USER_FLOWS.md` — understand user experience
4. `QR_SYSTEM.md`, `SAFETY_TRUST_POLICY.md` — domain-specific deep dives
5. `DEPLOYMENT.md` — when shipping to production
